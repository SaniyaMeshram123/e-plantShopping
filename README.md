# Paradise Nursery

## Project Name
Paradise Nursery Shopping Application

## Description
Paradise Nursery is a React-based online plant shopping application.

The application allows users to:
- Browse houseplants by category
- View plant images, names, and prices
- Add plants to the shopping cart
- View the number of items in the cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cart amount
- Continue shopping
- Use the checkout option

## Technologies Used
- React.js
- Redux Toolkit
- React Redux
- React Router
- Vite
- CSS

## Features
- Responsive landing page
- Plant categories
- Dynamic shopping cart
- Redux state management
- Quantity management
- Cart total calculation
- Checkout placeholder
- Navigation between Home, Plants, and Cart
